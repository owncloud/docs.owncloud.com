== Documentation by Product

=== ownCloud Infinite Scale (oCIS)

ownCloud Infinite Scale (oCIS) is ownCloud's cloud-native, microservices-based platform for file sync and share, deployable as a single binary, with Docker Compose, or on Kubernetes, without external dependencies like PHP or a database. The documentation serves administrators who deploy and operate oCIS and developers who extend it, covering spaces, security, and the bundled ownCloud Web.

=== ownCloud Classic (Server)

ownCloud Classic is the open source, LAMP-stack-based ownCloud server for file sync and share that you install and control in your own environment, keeping your data on your own infrastructure. The documentation serves administrators who install, configure, and operate an ownCloud Classic server and developers who write apps for it.

xref:server:ROOT:index.adoc[Open the ownCloud Classic documentation] for the latest stable release, or choose a version:

=== Desktop App

The ownCloud desktop app syncs files between your computer and ownCloud Infinite Scale or ownCloud Classic, with per-space sync connections for Infinite Scale. The documentation is for users who install, configure, and use the desktop app.

ownCloud Web is the modern web interface bundled with ownCloud Infinite Scale, built with Vue.js and customizable to your corporate identity. The documentation covers using the ownCloud web user interfaces in the browser, for administrators and users.
