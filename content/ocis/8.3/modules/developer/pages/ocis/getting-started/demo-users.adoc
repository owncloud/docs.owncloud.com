= Demo Users
:toc: right
:toclevels: 3

oCIS has the option to create demo users during the first startup. These enable you to do quick testing and developing.

[NOTE]
====
To create the demo users, run the initial setup step with an additional environment variable.

[source,bash]
----
IDM_CREATE_DEMO_USERS=true ./bin/ocis server
----

This will generate the demo users listed in the table below. By default, it only generates the admin and one user for IDP and Reva respectively.
====
