| xref:deployment/services/env-vars-special-scope.adoc#extended-environment-variables[Extended Environment Variables]
| GRPC_CLIENT_KEEPALIVE_TIME
| How long a grpc client connection with an ongoing request may stay silent before the server is pinged to check whether it is still answering. Set a duration like '20s' to enable detection of unresponsive peers. Leaving it unset, or at '0', sends no pings at all, which is grpc's own default. Values below '10s' are raised to '10s' by grpc. Make sure to include the unit suffix, a bare number is not a valid duration.
| 0s

| GRPC_CLIENT_KEEPALIVE_TIMEOUT
