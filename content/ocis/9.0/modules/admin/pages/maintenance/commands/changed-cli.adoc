== Affected CLI Commands

See the link for a detailed description of the respective CLI command if available.

* xref:maintenance/commands/recalculate-treesize.adoc[Recalculate Space Treesize] +
This CLI command has been added to correct drifting quota usage by recalculating the treesize of every directory in a space from the actual sizes of its children. Infinite Scale must be shut down before running in write mode.

* xref:maintenance/commands/commands.adoc#reset-password-for-idm-users[Reset Password for IDM Users] +
The `ocis idm resetpassword` command now also supports resetting service account passwords (`libregraph`, `idp`, `reva`) via `--user-type service`. After a service account password is changed, affected environment variables must be updated and Infinite Scale restarted.

* xref:maintenance/commands/commands.adoc#reindex-spaces-for-search[Reindex Spaces for Search] +
The `ocis search index` command has been extended with a `--timeout` flag (default `10m`, `0` = no limit) to allow indexing of large spaces or spaces with slow content extractors that previously failed with a context-cancelled error.

* xref:maintenance/commands/commands.adoc#manage-expired-or-stale-uploads[Manage Expired or Stale Uploads] +
The `ocis storage-users uploads sessions` command has been extended with an `--orphaned` flag to filter sessions whose node metadata is unreadable. Such sessions can never complete processing and can be cleaned up with `--clean`.
