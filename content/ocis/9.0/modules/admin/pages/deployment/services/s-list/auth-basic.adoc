The `auth-basic` service validates HTTP Basic authentication for clients that cannot handle OpenID Connect, such as some WebDAV clients. It does not validate credentials itself but delegates to a configurable auth manager, with LDAP being the recommended option. This page explains how to enable the service and choose an auth manager.

== Introduction

{description}

The `auth-basic` service is responsible for validating authentication of incoming requests. To do so, it will use the configured `auth manager`, see the `Auth Managers` section. Only HTTP basic auth requests to ocis will involve the `auth-basic` service.

To enable `auth-basic`, you first must set `PROXY_ENABLE_BASIC_AUTH` to `true`.

NOTE: The basic authentication implementation does not support cookies and is therefore not intended to be used for benchmarks.

== Auth Managers

Since the `auth-basic` service does not do any validation itself, it needs to be configured with an authentication manager. One can use the `AUTH_BASIC_AUTH_MANAGER` environment variable to configure this.

=== LDAP Auth Manager

Setting `AUTH_BASIC_AUTH_MANAGER` to `"ldap"` will configure the `auth-basic` service to use LDAP as auth manager. This is the recommended option for running in a production and testing environment. More details on how to configure LDAP with ocis can be found in the admin docs.

=== Other Auth Managers

The possible auth mangers which can be selected are `"ldap"` and `"owncloudsql"`. Those are tested and usable though `"ldap"` is the recommend manager. Refer to the admin docs for additional information about those.

== Scalability

Scalability, just like memory and CPU consumption, are highly dependent on the configured auth manager. When using the recommended one which is `"ldap"`, there is no persistance as requests will just be forwarded to the LDAP server. Therefore, multiple instances of the `auth-basic` service can be started without further configuration. Be aware, that other auth managers might not allow that.

== FAQ

=== How Do I Enable Basic Authentication?
Set `PROXY_ENABLE_BASIC_AUTH` to `true` on the xref:{s-path}/proxy.adoc[proxy] service. Clients then authenticate by sending an HTTP Basic `Authorization` header; only HTTP basic auth requests involve the `auth-basic` service.

=== Which Auth Manager Should I Use?
`"ldap"` is the recommended auth manager for production and testing environments. `"owncloudsql"` is also supported but not recommended. Select the manager with the `AUTH_BASIC_AUTH_MANAGER` environment variable.

=== Does Basic Authentication Support Cookies?
No. The basic authentication implementation does not support cookies and is therefore not intended to be used for benchmarks.
