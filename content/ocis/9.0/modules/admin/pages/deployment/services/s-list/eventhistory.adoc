== FAQ

=== Which Port Does the Eventhistory Service Listen On?
The `eventhistory` service listens on gRPC port `9274` by default.

=== Can Eventhistory Run Without an Event System?
No. Running the `eventhistory` service without an event system like NATS is not possible, because it consumes all events from the configured event system.

=== How Do Other Services Retrieve Events?
Other services call the `eventhistory` service via gRPC. The request must contain the event ID that should be retrieved.
