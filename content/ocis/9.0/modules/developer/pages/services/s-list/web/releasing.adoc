== Releasing

The source code of ownCloud Web lives in the link:https://github.com/owncloud/ocis/tree/master/web[web folder] of the oCIS repository. There is no separate Web release that needs to be pulled into oCIS: every oCIS build compiles the Web frontend from the same commit and embeds it into the `web` service, which is part of the single binary and the `ocis server` command.

=== How Web Gets Into the Web Service

The `build-assets` target in `services/web/Makefile` builds the frontend and copies the result into the service assets (excerpt, `WEB_DIR` is `../../web`):

[source,make]
----
build-assets:
	cd $(WEB_DIR) && pnpm install && pnpm check:types && pnpm build
	cp $(WEB_DIR)/config/config.json.dist $(WEB_DIR)/dist/
	cp -r $(WEB_DIR)/dist/. assets/core/
----

CI runs this target as part of `ci-node-generate`. Changes to Web are therefore released with the next oCIS release of the branch they are merged into.
