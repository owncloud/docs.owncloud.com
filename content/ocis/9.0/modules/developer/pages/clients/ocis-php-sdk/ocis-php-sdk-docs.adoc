The passthrough block below embeds the phpDocumentor HTML output in an iframe.

The iframe src is intentionally set to "about:blank" and resolved at runtime via JavaScript.
This avoids hardcoding the Antora published path, which varies by component, version, and module.
The script derives the attachment URL by stripping everything from "/clients/" onward from the
current page's pathname and appending the known attachment path "/_attachments/ocis-php-sdk-docs/index.html".

The onload handler resizes the iframe to the full scrollHeight of the loaded document. This works because
both the Antora page and the attachment are served from the same origin (doc.owncloud.com), so the script
can access the iframe's contentWindow. The try/catch silently ignores the resize if cross-origin restrictions
apply in local or preview builds.
////

<iframe id="php-sdk-docs-frame"
  src="about:blank"
  style="width:100%;border:none;min-height:300px;"
  title="oCIS PHP SDK API Reference">
</iframe>
<script>
  (function () {
    var path = window.location.pathname;
    var moduleBase = path.substring(0, path.indexOf('/clients/'));
    var frame = document.getElementById('php-sdk-docs-frame');
    frame.src = moduleBase + '/_attachments/ocis-php-sdk-docs/index.html';
    frame.onload = function () {
      try {
        this.style.height =
          this.contentWindow.document.documentElement.scrollHeight + 'px';
      } catch (e) {}
    };
  })();
</script>
