= Setup With oCIS
:toc: right
:toclevels: 3
:description: Set up ownCloud Web for local development against an oCIS backend: clone the repo, install dependencies and run the web build.

== Setting Up Web

* Clone the link:https://github.com/owncloud/ocis/[repository].
* Change to the `web` directory of the repository (`cd ocis/web`). Run all `pnpm` commands from there.
* Initally install all dependencies by running `pnpm install`.
* Copy `config/config.json.sample-ocis` to `config/config.json` (inside the `web` directory) and adjust values if required.

== Running Web

* Start bundling web with a watcher by running `pnpm build:w` from the `web` directory. The bundle is written to `web/dist`.

== Setting Up oCIS

* Setup oCIS by following the xref:ocis/getting-started/index.adoc[setup instructions]
* Start oCIS with local links to your bundled web frontend and config by running the following command from the `ocis` folder of the repository (where the oCIS binary is built to `bin/ocis`), adjust the paths as necessary:
+
[source,bash]
----
WEB_ASSET_CORE_PATH=../web/dist \
WEB_UI_CONFIG_FILE=../web/config/config.json \
OCIS_INSECURE=true \
IDM_CREATE_DEMO_USERS=true \
./bin/ocis server
----

== Start oCIS

* Open `\https://localhost:9200` and accept the certificate.
* When signing in, use one of the xref:ocis/getting-started/demo-users.adoc[available demo users].
* Whenever code changes are made, `pnpm build:w` rebuilds web and you need to manually reload the browser page (no hot module reloading).

== Running Tests

For testing, please refer to the xref:clients/web/testing/index.adoc[testing docs].
