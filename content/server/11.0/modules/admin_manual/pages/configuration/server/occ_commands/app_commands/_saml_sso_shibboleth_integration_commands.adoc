= SAML/SSO Shibboleth Integration (Enterprise Edition only)

Included in the complete tarball and the Docker image, see xref:installation/apps/apps_supported.adoc[Supported Apps in ownCloud].

`shibboleth:mode` sets your Shibboleth mode to `notactive`, `autoprovision`, or `ssoonly`

[source,docker,subs="attributes+"]
----
{occ-command-example-prefix-docker} shibboleth:mode [mode]
----
