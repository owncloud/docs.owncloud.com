= Supported Apps in ownCloud
:toc: right
:page-aliases: installation/apps/mediaviewer/index.adoc, installation/apps_supported.adoc

== Introduction

The apps on this page are no longer distributed through the ownCloud Marketplace. They ship with ownCloud itself:

* The *standard* tarball contains the core apps and the apps listed under xref:included-in-every-tarball[Included in Every Tarball].
* The *complete* tarball additionally contains the apps listed under xref:included-in-the-complete-tarball[Included in the Complete Tarball].

The official ownCloud Docker image is built from the complete tarball, so it contains all of them.

A few apps are not bundled at all. They are listed under xref:available-separately[Available Separately] and are downloaded from their GitHub releases page, where a release for this version exists.

Apps without a link are self-explanatory.

[NOTE]
====
* The _Gallery_ and _Files VideoPlayer_ apps are deprecated, archived, and no longer maintained. Use the Files Media Viewer app instead.
* Before Files Media Viewer 1.0.4, the _Gallery_ and _Files VideoPlayer_ apps need to be **uninstalled before installing** the Media Viewer app.
* Starting with Files Media Viewer 1.0.4, the _Gallery_ and _Files VideoPlayer_ apps need to be **disabled before using** the Files Media Viewer app.
